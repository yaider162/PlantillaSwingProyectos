# Juego de Trayectoria de Ovnis

## Descripción del Proyecto

Este proyecto es un juego donde puedes controlar las trayectorias de los ovnis. El juego te permite visualizar las trayectorias de los ovnis y cambiar sus rutas usando el ratón.

## Autor

## Versión de JDK

Este proyecto está definido para ejecutarse en **JDK 21**.

## Cómo Ejecutar el Proyecto

1. **Clonar el repositorio:**
   ```sh
   git clone https://github.com/yaider162/PlantillaSwingProyectos
    ```
## Iniciar el Juego:    
Al iniciar el juego puedes configurar los parámetros:  

1. Se te pedirá que ingreses el número de ovnis, el tiempo de aparición (en milisegundos) y la velocidad (recomendada entre 10-30).
Selecciona el color de los ovnis. 

2. Haz clic en "Aceptar" para iniciar el juego con los parámetros especificados.
Cambiar Trayectorias de los Ovnis:  

3. Haz clic derecho sobre un ovni para cambiar su trayectoria. Un mensaje te informará que puedes cambiar la trayectoria con un clic derecho.

### Visualizar Trayectorias:  
Habrá una casilla de verificación etiquetada como "Mostrar Trayectorias". Al seleccionarla, se mostrarán las trayectorias de los ovnis
